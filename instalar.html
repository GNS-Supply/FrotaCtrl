    Instalar manualmente

    Android (Chrome)
    1. Abra o endereço do sistema no Chrome (não dentro do WhatsApp, Instagram ou e-mail).
    2. Use uma aba normal (não anônima) e deixe o "Site para computador" desligado.
    3. Toque no menu ⋮ (três pontos).
    4. Escolha Instalar app. Se só aparecer "Adicionar à tela inicial", volte aqui e veja qual verificação acima está em vermelho.
    5. Confirme em Instalar. O ícone F aparece na tela inicial.
    iPhone / iPad (Safari)
    1. Abra o endereço no Safari.
    2. Toque em Compartilhar (quadrado com seta para cima).
    3. Role e toque em Adicionar à Tela de Início.
    4. Toque em Adicionar.

    Se acabou de publicar uma versão nova, espere 1–2 minutos (o GitHub Pages demora para atualizar) e recarregue esta página.
